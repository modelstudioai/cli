# Memory CLI 文档

Memory CLI 用于写入和检索长期记忆、维护记忆节点、管理画像模板并读取用户画像，以及导出 Skill 记忆。

- [命令用法指南](memory-cli-guide.md)：13 个 `bl memory` 命令的概念、约定、工作流和速查。分册为 [记忆节点](node.md)、[画像](profile.md)、[Skill 记忆](skill.md)。
- [能力矩阵](cli-matrix.md)：适用对象、参数范围、API 映射及使用边界。
- [用户技术指南](user-guide.md)：从配置到写入、检索、画像、Skill 和脚本集成的流程说明。
- [个人长期记忆 Skill](../../skills/bailian-memory/SKILL.md)：在本地 Agent 中启用生活与工作记忆，含首次配置和基础画像。
- [完整参数参考](../../skills/bailian-memory/reference/memory.md)：根据命令元数据自动生成。

命令手册按当前工作区的 `bl memory` 实现整理。已安装 CLI 的实际子命令以本机 `bl --version` 和 `bl memory --help` 为准。
